## ⚡ 最快运行方式（3步搞定）

### 如果你在Windows

```
1. 下载代码 → 右键解压
2. 进入文件夹 → 双击 start.bat
3. 打开浏览器 → 访问 http://localhost:5000
```

### 如果你想在线访问

```
1. 注册Heroku账号
2. 运行命令：heroku create my-app && git push heroku main
3. 访问：https://my-app.herokuapp.com
```

## 🆘 出现问题怎么办？

### 问题1：双击start.bat一闪而过
**原因**：Python未安装或未添加到PATH

**解决**：
1. 下载Python：https://www.python.org/downloads/
2. 安装时✅勾选 "Add Python to PATH"
3. 重新运行start.bat

---

### 问题2：安装依赖很慢
**解决**：修改start.bat，在pip命令后添加：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 问题3：无法访问localhost:5000
**检查清单**：
- [ ] start.bat是否还在运行？（不要关闭黑色窗口）
- [ ] 看到类似 "Running on http://127.0.0.1:5000" 的提示吗？
- [ ] 尝试访问 http://127.0.0.1:5000

---

### 问题4：Heroku部署失败
**查看日志**：
```bash
heroku logs --tail
```

**常见错误**：
- "Could not find a version" → 检查requirements.txt
- "ModuleNotFoundError" → 检查文件路径
- "Build failed" → 查看完整错误信息
