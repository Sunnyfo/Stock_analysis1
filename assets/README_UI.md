# 智能股票分析系统 - Web界面使用说明

## 🌟 功能介绍

本系统提供简洁易用的Web图形界面，支持以下核心功能：

### 1. 智能诊股
- 🔍 支持多种搜索方式：
  - 股票代码（如：600519）
  - 股票名称（如：贵州茅台）
  - 首字母缩写（如：GZMT）
- 📊 深度分析股票的基本面和技术面
- 📤 支持多种发送渠道（飞书、邮件、两者都发送）

### 2. 智能选股
- 🎯 多维度筛选条件：
  - 行业选择（科技、金融、医疗、消费等）
  - 市值范围
  - 市盈率（PE）范围
  - K线周期（日线、周线、月线）
  - 技术指标（MACD金叉、RSI超卖、放量上涨、突破阻力）
  - 自定义条件
- 🚀 智能推荐符合条件的优质股票

### 3. 系统设置
- 📧 默认邮箱管理
- 🎨 消息格式配置
- 🔗 飞书Webhook设置

## 🚀 快速开始

### 方法一：直接打开HTML文件
1. 找到 `assets/index.html` 文件
2. 双击文件，在浏览器中打开
3. 开始使用

### 方法二：本地服务器（推荐）
```bash
# 使用Python启动简单HTTP服务器
cd assets
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server assets -p 8000
```
然后在浏览器中访问：`http://localhost:8000`

## 📖 详细使用指南

### 诊股分析

#### Step 1: 搜索股票
在"股票搜索"输入框中输入：
- 股票代码：`600519`
- 股票名称：`贵州茅台` 或 `茅台`
- 首字母缩写：`GZMT`

系统会实时显示匹配结果，点击选择股票。

#### Step 2: 选择发送渠道
- **飞书**：将分析结果发送到飞书群聊（需要配置Webhook）
- **邮件**：将分析结果发送到指定邮箱
- **两者都发送**：同时发送到飞书和邮件

#### Step 3: 配置收件人（如选择邮件发送）
- 在"收件人邮箱"栏输入邮箱地址
- 点击"添加"按钮
- 可添加多个收件人
- 点击邮箱标签右侧的"×"可删除

#### Step 4: 开始分析
点击"开始诊断"按钮，系统将：
- 自动分析选中的股票
- 生成专业分析报告
- 通过选择的渠道发送结果

### 智能选股

#### Step 1: 设置筛选条件

**行业选择**
- 从下拉菜单选择目标行业
- 可选择"全部行业"进行全市场筛选

**市值范围**
- 输入最小市值（单位：亿）
- 输入最大市值（单位：亿）
- 可只填其中一个

**市盈率范围**
- 输入最小PE值
- 输入最大PE值
- PE越低通常表示估值越低

**K线周期**
- 日线：适合短期分析
- 周线：适合中期分析
- 月线：适合长期分析

**技术指标（多选）**
- MACD金叉：趋势向上信号
- RSI超卖：可能反弹信号
- 放量上涨：资金流入信号
- 突破阻力：突破关键位信号

**其他条件**
- 自由输入其他筛选要求
- 如：国企、分红率高、成长性好等

#### Step 2: 选择发送渠道
与诊股分析相同

#### Step 3: 开始选股
点击"开始选股"按钮，系统将：
- 根据条件筛选股票
- 生成选股报告
- 推荐优质股票
- 通过选择的渠道发送结果

### 系统设置

#### 默认邮箱管理
- 在"默认收件人邮箱"中添加常用邮箱
- 添加后每次分析时无需重复输入
- 便于团队协作使用

#### 飞书Webhook配置
1. 在飞书群聊中添加自定义机器人
2. 复制Webhook地址
3. 粘贴到"飞书Webhook地址"输入框
4. 保存设置

#### 消息格式
- **富文本（推荐）**：格式美观，易于阅读
- **交互式卡片**：支持按钮等交互元素

## 📝 注意事项

1. **浏览器兼容性**
   - 推荐使用 Chrome、Firefox、Edge 最新版本
   - 不支持 IE 浏览器

2. **数据安全**
   - 所有数据仅存储在本地浏览器
   - 不会上传到任何服务器
   - 清除浏览器数据会丢失设置

3. **实际部署**
   - 当前为静态页面，需要配合后端API
   - 需要配置邮件和飞书集成
   - 建议部署到Web服务器

4. **股票数据**
   - 当前股票数据为示例数据
   - 实际使用时需要接入真实股票数据库
   - 可以通过API获取实时股票信息
